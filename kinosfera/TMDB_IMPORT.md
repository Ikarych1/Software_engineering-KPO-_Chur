# Импорт каталога из TMDB

Сайт поддерживает официальный API TMDB. Старый импорт бесплатных наборов IMDb
сохранён отдельно: он может обновлять рейтинг IMDb в тех же карточках.
Новые зависимости не требуются — используются Flask, SQLite и стандартная библиотека Python.

## Подключение

1. Получите API Read Access Token в [настройках аккаунта TMDB](https://www.themoviedb.org/settings/api).
2. Перезапустите сервер сайта после установки этой версии.
3. Откройте «Управление КиноСферой → TMDB · Импорт CSV».
4. Введите токен в поле подключения и нажмите «Проверить и сохранить ключ».
5. Загрузите список CSV и запустите импорт. Можно закрыть страницу: работа продолжается на сервере.

Поддерживается также API Key v3. Вместо ввода в админ-панели можно задать
переменную окружения `TMDB_READ_TOKEN` или `TMDB_API_KEY` перед запуском сервера.
Переменная окружения имеет приоритет; заменить такой ключ нужно на сервере.
Сохранённый через админ-панель ключ лежит в `.local/tmdb-settings.json`.
Эта папка исключена из Git. Ключ не возвращается в HTML/JSON и не включается в отчёты.
Не публикуйте содержимое `.local`.

## Формат списка

CSV в UTF-8, с запятыми либо точками с запятой. Максимум **20 000 строк и 10 МБ**.
Прежние списки IMDb подходят без изменения:

```csv
imdb_id,title,year
tt0816692,Интерстеллар,2014
tt3659388,Марсианин,2015
```

Пример: `examples/tmdb_movies.csv`. Поля `title` и `year` необязательны при наличии ID.
`title` задаёт название новой карточки; при заполнении существующей ручное название сохраняется.
Если год из файла не совпадает с годом источника, строка пропускается.

Можно использовать непосредственно TMDB ID:

```csv
tmdb_id,type
157336,movie
1399,series
```

Числовой TMDB ID требует `type`: `movie` или `series` (`tv` тоже принимается).
У фильмов и сериалов разные пространства ID. Вместо числа можно указать ссылку
вида `https://www.themoviedb.org/movie/157336` или `/tv/1399` с полным доменом;
тогда тип определяется ссылкой. Поддерживается и поиск по точному названию с годом,
но для больших списков лучше использовать ID. Неоднозначные результаты и поиск
с несколькими страницами пропускаются: импортёр не выбирает случайный первый фильм.
Неизвестные столбцы и некорректный CSV отклоняются до запуска.

## Поля карточки

Импортируются название, оригинальное название, описание, слоган, год,
жанры, страны производства, длительность, актёры и режиссёры, российское
возрастное ограничение при наличии, постер, фон и собственный рейтинг TMDB.
Для сериалов используется длительность серии; серии и раздачи не создаются автоматически.

Первый запрос использует `ru-RU`. При отсутствии описания выполняется запрос `en-US`.
Часть имён и названий стран может оставаться на языке источника.
Отсутствующие сведения не выдумываются. Без года или длительности новую карточку
нужно добавить вручную; причина отображается в отчёте. MPAA и признак adult не
преобразуются в российское возрастное ограничение.

Постеры и фоны загружаются браузером с `image.tmdb.org`; 20 тысяч изображений
не скачиваются импортёром на диск. Существующие локальные изображения имеют приоритет.
Видеоисточники, видеопетля главной страницы и пользовательские данные добавляются отдельно.

Рейтинг TMDB отображается с подписью **TMDB**. Он не записывается в поля IMDb или
Кинопоиска. Рейтинг IMDb можно получить существующим импортом IMDb, используя тот же
идентификатор. Оценки и отзывы пользователей КиноСферы хранятся отдельно.

## Обновление и повторный запуск

При совпадении TMDB ID и типа либо IMDb ID обновляется существующая карточка.
Для старых карточек без ID используется точное совпадение названия/оригинального
названия, года и типа. Конфликтующие карточки и разные ID пропускаются.
Таблицы имеют уникальные индексы для внешних идентификаторов.

Сначала заполняются пустые поля. При повторном импорте обновляются поля, значение
которых всё ещё совпадает с предыдущим импортом TMDB. Изменённые вручную значения
сохраняются. Ручное название, описания, загруженные изображения, публикация,
торренты, ревизия источника, история просмотров, отзывы и оценки не сбрасываются.
Удалённая вручную связь с импортированным значением может быть заполнена снова,
если поле пустое; отдельного режима «запретить обновление поля» пока нет.

## Большие списки и восстановление

Задания, строки CSV, результаты и прогресс хранятся в SQLite, а не в памяти процесса.
Одна транзакция атомарно сохраняет карточку и результат соответствующей строки.
При отмене готовые карточки остаются. После ошибки, отмены или перезапуска
сервер показывает кнопку «Продолжить импорт»; обработанные строки повторно не выполняются.
Автоматического возобновления сетевых запросов после перезапуска нет.
Последние задания доступны на странице импорта; отчёты содержат все строки, включая
ещё не обработанные. На странице и в ответе статуса показывается не более 100 результатов.

Один процесс импорта TMDB работает с каталогом одновременно. Блокировка ОС
действует и между несколькими экземплярами сервера/CLI; аварийное завершение освобождает её.
Запросы ограничены четырьмя в секунду и выполняются последовательно.
На 429 и временные сетевые/серверные ошибки есть ограниченные повторные попытки;
после исчерпания попыток прогресс остаётся доступным для продолжения.
Ответы кешируются на 7 суток. Опция свежих данных обходит кеш; ключи не входят в его содержимое.

20 тысяч фильмов означают десятки тысяч запросов, если ответы ещё не кешированы.
Реальное время зависит от сети, полноты данных, количества запросов на фильм и ограничений сервиса.
Офлайн-проверка нагрузки проверяет код и SQLite, но не измеряет скорость публичного API.

## Командная строка

После настройки ключа:

```powershell
.venv\Scripts\python.exe import_tmdb.py examples/tmdb_movies.csv
.venv\Scripts\python.exe import_tmdb.py movies.csv --draft --refresh
.venv\Scripts\python.exe import_tmdb.py --resume ИДЕНТИФИКАТОР_ЗАДАНИЯ
```

`--database` задаёт другой SQLite-файл. Импортёр выводит ID задания и прогресс.
Он не запускает Flask, торрент-движок и медиаплеер. Админ-панель и CLI используют
общую очередь при выборе одного файла базы.

## Проверки

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -p test_tmdb_import.py -q
.venv\Scripts\python.exe tests/e2e_tmdb_import.py
.venv\Scripts\python.exe tests/benchmark_tmdb_import.py
```

Тесты используют временные базы и подмену ответов API. В пользовательский каталог
тестовые фильмы не добавляются. Настоящий успешный запрос к TMDB требует вашего ключа.
