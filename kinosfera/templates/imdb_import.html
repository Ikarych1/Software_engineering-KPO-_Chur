Нужны описания и обложки? Используйте импорт из TMDB. Этот раздел остаётся для официальных наборов и рейтингов IMDb.

Список фильмов

Укажите IMDb ID или ссылку. В столбце title можно задать русское название карточки. Без ID поиск идёт по точному названию и году; для русского названия при необходимости загружается дополнительный набор IMDb. Неоднозначные совпадения будут пропущены.

imdb_id,title,year
tt0816692,Интерстеллар,2014
tt3659388,Марсианин,2015

При первой загрузке потребуются дополнительные наборы IMDb общим размером около 1 ГБ. Их загрузка и чтение займут больше времени.

Обычно используются ранее загруженные файлы. Включите опцию, чтобы получить свежие рейтинги и новые фильмы.

Что будет добавлено

  • Название и оригинальное название
  • Год, жанры и длительность
  • Рейтинг IMDb и число голосов
  • Ссылка на IMDb и идентификатор фильма
  • Актёры и режиссёры — по желанию

Первый импорт загружает официальные наборы IMDb размером в сотни мегабайт. Затем файлы используются повторно. Прогресс отображается ниже; страницу можно перезагрузить.

В бесплатных наборах нет описаний сюжета, постеров, стран производства и возрастных сертификатов. Эти поля можно заполнить в редакторе карточки. Видеоисточники добавляются отдельно.

Повторный импорт обновляет данные IMDb в существующей карточке. Ваши описания, обложки, публикация, раздачи и прогресс просмотра сохраняются.
