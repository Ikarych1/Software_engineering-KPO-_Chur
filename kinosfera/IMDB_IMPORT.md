# Импорт каталога из IMDb

Для описаний, изображений и остальных сведений добавлен отдельный
[импорт из TMDB](TMDB_IMPORT.md), поддерживающий до 20 000 строк.
Этот раздел описывает прежний импорт официальных наборов IMDb с лимитом 500 строк.

Источник — официальные [IMDb Non-Commercial Datasets](https://data.imdb.com/non-commercial-datasets/).
Ключ API и платная подписка не нужны. Данные загружаются напрямую с `datasets.imdbws.com`.
Этот импортёр не использует сторонние API и не разбирает HTML-страницы IMDb.

## Через сайт

1. Войдите под администратором.
2. Откройте `/admin` и нажмите **IMDb · Импорт CSV**. Прямой адрес: `/admin/imdb/`.
3. Скачайте пример CSV, замените строки своим списком и загрузите файл.
4. При необходимости включите актёров и режиссёров. Для сохранения черновиков снимите
   «Опубликовать новые карточки в каталоге».
5. Нажмите **Импортировать в каталог**. Дождитесь отчёта и откройте добавленные карточки.

Импорт идёт в фоне. Перезагрузка страницы сохраняет просмотр текущего результата
через параметр `?job=…`. При перезапуске самого сервера сведения о выполнявшейся задаче
теряются: загрузите CSV ещё раз. Полностью загруженные наборы остаются в кеше,
повторный импорт не создаёт дубликаты. Во время импорта доступна отмена.

## Формат файла

CSV в **UTF-8** (BOM допустим), не более **500 строк и 512 КБ**. Разделитель — запятая
или точка с запятой. Названия с запятой заключаются в двойные кавычки.

Рекомендуемый вариант:

```csv
imdb_id,title,year
tt0816692,Интерстеллар,2014
tt3659388,Марсианин,2015
tt2582802,Одержимость,2014
```

- `imdb_id` — IMDb ID либо ссылка вроде `https://www.imdb.com/title/tt0816692/`.
- `title` — название карточки, например русское. При указанном ID этот столбец необязателен.
- `year` — год для проверки совпадения; необязателен.

Минимальный файл:

```csv
imdb_id
tt0816692
tt3659388
```

Можно передать названия без идентификаторов:

```csv
title,year
The Martian,2015
Марсианин,2015
```

Поиск по названию точный, без учёта регистра и лишних пробелов. Для русских названий,
которые не нашлись в основном наборе, автоматически загружается `title.akas.tsv.gz`.
Это ещё один крупный файл. При нескольких совпадениях запись пропускается, а отчёт
показывает варианты и их IMDb ID. Программа не выбирает случайный фильм. Если IMDb
не указал год или длительность, запись также пропускается с пояснением.

Поддерживаются фильмы, телефильмы, сериалы и мини-сериалы. Отдельные эпизоды и другие
типы записей не импортируются как самостоятельные карточки. Видео и сезоны подключаются
в существующем редакторе отдельно.

## Какие данные добавляются

Базовый импорт получает название, оригинальное название, год, жанры, длительность,
рейтинг и число голосов IMDb, идентификатор и ссылку на IMDb. Жанры переводятся
по встроенному словарю на русский язык. Названия, фамилии и описания автоматически
не переводятся.

Опция актёров и режиссёров использует `title.crew`, `title.principals` и `name.basics`.
В карточку попадают доступные основные актёры из principals, а не полная фильмография.

В бесплатных наборах **нет постеров, описаний сюжета, стран производства и возрастных
сертификатов**. У новых карточек используется обложка-заглушка, описание «Описание пока
не добавлено», неизвестный возраст обозначается «—». Заполните эти поля вручную.
Флаг `isAdult` не подменяет возрастной сертификат.

Импорт добавляет метаданные, а не видеоисточники. Без подключённого видео карточка
видна в каталоге со статусом «Скоро в библиотеке».

## Повторный импорт и сохранность данных

- Основной ключ — IMDb ID, с уникальным индексом в SQLite.
- Для старых карточек без IMDb ID проверяется совпадение названия/оригинального
  названия, года и типа. Если совпадение единственное, карточка связывается с IMDb.
- Повторный импорт обновляет рейтинг IMDb, число голосов и информацию об источнике.
  Общий рейтинг карточки также получает актуальный рейтинг IMDb; оценки пользователей
  хранятся отдельно и не изменяются.
- Существующие названия, описания, обложки, публикация, раздачи, серии, отзывы и прогресс
  сохраняются. Актёры и режиссёр дополняются, если соответствующие поля ещё пусты.
- Все изменения одного импорта выполняются в одной транзакции. Ошибка записи или
  отмена до завершения транзакции откатывает изменения каталога.
- Неоднозначные, отсутствующие и неполные записи пропускаются; остальные импортируются.

## Загрузка и кеш

Первый базовый импорт загружает два файла: `title.basics.tsv.gz` и `title.ratings.tsv.gz`
(сотни мегабайт). Поиск русских названий и добавление актёров требуют дополнительных
крупных файлов. Во время загрузки отображается число полученных мегабайт, во время
чтения — число обработанных строк.

Наборы хранятся в `.local/imdb/`, читаются последовательно без распаковки целиком
в оперативную память. Файлы повторно используются, пока вы не включите «Заново загрузить
наборы IMDb». Сам IMDb обновляет исходные наборы ежедневно; приложение не скачивает
их заново автоматически при каждом импорте. Временные незавершённые загрузки удаляются.

Путь кеша сайта можно задать переменной окружения `CINEMA_IMDB_CACHE_DIR`.
Одновременно через админ-панель выполняется один импорт. Последние 20 задач доступны
до перезапуска процесса сервера. Отчёт можно скачать в CSV.

## Через командную строку

Из папки проекта:

```powershell
.venv/Scripts/python.exe import_imdb.py examples/imdb_movies.csv
```

Дополнительные параметры:

```powershell
.venv/Scripts/python.exe import_imdb.py movies.csv --draft --credits --report .local/imdb-report.json
.venv/Scripts/python.exe import_imdb.py movies.csv --refresh
```

`--database` задаёт другую SQLite-базу, `--cache` — другую папку наборов. По умолчанию
используется настоящая база `.local/cinema.sqlite3`. CLI не запускает веб-сервер,
торрент-движок и воспроизведение. Дополнительных Python-пакетов не требуется.

Код завершения: `0` — все строки обработаны, `2` — часть записей пропущена,
`1` — ошибка, `130` — прерывание Ctrl+C.

При обновлении проекта перезапустите существующий сервер, чтобы в админ-панели
появилась новая страница.

## Проверка

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -p test_imdb_import.py -v
.venv/Scripts/python.exe tests/e2e_imdb_import.py
```

Проверки используют временные базы и небольшие gzip-наборы официального формата,
не изменяют настоящие аккаунты и каталог. Скриншоты браузерной проверки сохраняются
в `tests/artifacts/imdb-import-desktop.png` и `imdb-import-mobile.png`.
