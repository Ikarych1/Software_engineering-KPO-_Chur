# КиноСфера

Веб-приложение онлайн-кинотеатра: каталог и поиск, карточки произведений,
регистрация, личная библиотека, административная панель, видеоплеер,
комнаты совместного просмотра и импорт метаданных IMDb/TMDB.

## Быстрый запуск

Нужны Python 3.12, а для обработки видео — FFmpeg и FFprobe в `PATH`.
Команды выполняются из папки `kinosfera` после клонирования репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py --port 5050
```

Откройте <http://127.0.0.1:5050/>. Первый зарегистрированный аккаунт получает
роль администратора. Приложение создаёт локальную SQLite-базу
`.local/cinema.sqlite3` и заполняет начальный демонстрационный каталог.
Источники видео добавляются администратором отдельно.

Для Linux/macOS замените `.venv\Scripts\python.exe` на `.venv/bin/python`.
Сервер использует Flask/Jinja, HTML/CSS/JavaScript, SQLite, libtorrent,
FFmpeg/FFprobe, HLS и hls.js; обновления комнат передаются через SSE.

## Структура

- `app.py`, `accounts.py`, `library.py`, `rooms.py` — веб-приложение,
  учётные записи, библиотека и комнаты.
- `database.py`, `engagement_schema.py`, `migrate_engagement.py` — хранение
  данных и совместимое расширение схемы.
- `playback.py`, `torrent_*.py`, `series.py` — источники, плеер и серии.
- `imdb_*.py`, `tmdb_*.py`, `import_imdb.py`, `import_tmdb.py` — импорт каталога.
- `templates/`, `static/` — страницы, стили, скрипты и изображения.
- `examples/` — примеры CSV для импорта, включая список из 20 000 произведений.
- `tests/` — автоматизированные проверки и небольшие сгенерированные
  медиафикстуры для локальных тестов.
- `datasets/` — схемы, документация, генераторы и ERD тестовых наборов.

## База данных и большие наборы

Рабочая и тестовая базы используют 30 общих таблиц приложения и
представление `episode_activity`. После переноса большого набора в рабочую
базу добавляется служебная таблица `dataset_imports` для защиты от повторного
импорта. Таблица `cache_versions` обновляет кэш статистики при изменениях данных.
Актуальные определения основных таблиц:

- [Физическая SQL-схема](datasets/cinema_project_v3/schema.sql).
- [Описание актуальной тестовой БД](datasets/cinema_project_v3/README.md).
- [ERD](datasets/cinema_project_v3/erd/ERD.md) и
  [редактируемая диаграмма](datasets/cinema_project_v3/erd/cinema_test.drawio).
- [Примеры SQL-запросов](datasets/cinema_project_v3/example_queries.sql).

Готовые SQLite-файлы, CSV.gz с взаимодействиями, архивы датасетов, рабочие
аккаунты и кеш видео в GitHub не включены. Описания и отчёты в `datasets/`
относятся к отдельно подготовленным наборам; ссылки на большие файлы
заработают после их отдельного получения. Скриптам полной пересборки
нужны исходные данные и снимок каталога, описанные в соответствующих README.
Для обычного запуска сайта большой тестовый набор не нужен.

При локальной пересборке v3 пароль тестовых аккаунтов берётся из
`CINEMA_TEST_PASSWORD` или генерируется случайно. Реквизиты записываются
в локальный `datasets/cinema_project_v3/TEST_LOGIN.md`, исключённый из Git;
в публикуемом манифесте пароль не сохраняется.

Альтернативный локальный файл можно выбрать перед запуском:

```powershell
$env:CINEMA_DATABASE = 'C:\data\cinema_test.sqlite3'
.\.venv\Scripts\python.exe app.py --port 5050
```

Рекомендации используют MixDex, личные предпочтения, оценки, просмотры и закладки.
При первом входе нужно выбрать 3 жанра и 3 понравившихся произведения; старые
аккаунты без этого выбора тоже проходят настройку. Выбор сохраняется отдельно
от оценок и истории. Показы и клики рекомендованных карточек записываются после
подтверждения браузером. Обучение отдельной модели на MovieLens не выполняется.
Платёжные сценарии демонстрационные.

## Проверки

Основные проверки запускаются через стандартный `unittest`:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py" -v
```

Проверки плеера используют FFmpeg/FFprobe и локальные HTTP-серверы.
Сценарии `tests/e2e_*.py` дополнительно требуют Playwright и установленный
браузер. Инструкции и настройки медиаподсистемы приведены ниже.
