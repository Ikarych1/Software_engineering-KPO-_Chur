# Список из 20 000 фильмов и сериалов

Сформирован 2026-10-21 из официальных открытых наборов IMDb.
Это 20 000 отдельных тайтлов, а не эпизодов: каждый IMDb ID встречается один раз.

## Какой файл загрузить

- **`catalog_20000.csv` — рекомендуемый файл для импорта через TMDB.**
  Формат `imdb_id,title,year`. Столбец `title` намеренно пустой: импортёр сам
  получает название из TMDB с языком `ru-RU`. Год указан по IMDb.
- **`catalog_20000_with_titles.csv` — те же записи в том же порядке с названиями IMDb.**
  Удобен для просмотра списка; тоже принимается импортёром. При его загрузке
  название из CSV будет задано новой карточке, поэтому многие названия окажутся
  английскими или на другом языке источника.

Кодировка обоих файлов — UTF-8 с BOM, разделитель — запятая. Заголовок не входит
в 20 000 записей. Формат обоих файлов проверен настоящей функцией чтения CSV
из импортёра проекта; дубликатов идентификаторов нет.

Откройте «Админка → TMDB · Импорт CSV», подключите ключ и выберите основной файл.
Текущий импорт наборов IMDb имеет отдельный лимит 500 строк; этот список
предназначен для нового импортёра TMDB с лимитом 20 000.

Годы: **1915–2026**.
Анимационные работы и документальные фильмы входят в соответствующие типы;
они не выделяются в самостоятельные записи и не дублируются.
В списке 1,405 тайтлов с жанром Animation и 638
с жанром Documentary (жанры могут пересекаться).

## Принцип отбора

1. Из рейтингов IMDb взяты записи минимум с 1000 голосами.
2. Оставлены фильмы, телефильмы, телеспецвыпуски, видеофильмы, сериалы и мини-сериалы.
3. Исключены отдельные эпизоды, игры, музыкальные клипы, типы `short` и `tvShort`,
   записи с флагом IMDb `isAdult=1`, без жанров, без допустимого года или длительности.
   Допустимая длительность в этом проекте — от 1 до 720 минут.
4. Из 65,699 подходящих кандидатов выбраны первые 20 000 по числу голосов IMDb
   по убыванию. При равенстве учитывается рейтинг, затем IMDb ID.

Минимум голосов среди выбранных записей: **6,904**.
Это подборка широко оцениваемых произведений, а не официальный «IMDb Top 20 000»
и не список, отсортированный только по средней оценке.
