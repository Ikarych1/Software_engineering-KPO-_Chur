# Большой тестовый набор в рабочей базе

Рабочая база кинотеатра: `.local/cinema.sqlite3`. Источник:
`datasets/cinema_project_v3/cinema_test.sqlite3`. Исходный тестовый файл открывается
только для чтения и не используется вместо рабочей базы.

Перенос выполняет `merge_test_dataset.py`. Он добавляет 50 000 тестовых
пользователей, 6 219 466 оценок, отзывы, предпочтения, закладки, клипы,
просмотры и прогресс серий, комнаты и их сообщения, показы, клики, поиски,
отказы и журнал событий. В наборе сочетаются исходные оценки MovieLens и ранее
подготовленные тестовые данные; после переноса они участвуют в общей статистике
сайта. Происхождение данных описано в `datasets/cinema_project_v3/README.md`.

## Сохранение существующих данных

- Перед изменениями создаётся согласованная SQLite-копия в `.local/backups/`.
- Идентификаторы тестовых пользователей и связанных записей переназначаются;
  обновляются также ссылки внутри JSON, включая клипы, друзей и комнаты.
- Существующие аккаунты, хеши паролей, роли, подписки, настройки, оценки,
  просмотры, переписка и остальные личные данные сохраняются. Перед фиксацией
  исходные строки сравниваются с резервной копией по всем значениям колонок.
- Тестовый администратор импортируется с ролью `USER`. При совпадении email
  изменяется только адрес нового тестового аккаунта.
- 3 054 фильма остаются в существующем каталоге с прежними ID и видеоисточниками.
  Из тестового набора заполняются только отсутствующие или пустые метаданные
  (включая заглушки `—` и «нет данных»);
  уже заполненные значения сохраняются. Перед этим исходные значения карточек
  отдельно записываются в `.local/backups/catalog-before-enrichment-*.jsonl`.
- Сначала все связанные записи переносятся одной транзакцией. При ошибке перенос
  откатывается целиком. Заполнение пропусков карточек — отдельная транзакция.
- Таблица `dataset_imports` хранит SHA-256 источника и квитанцию переноса.
  Повторный запуск с тем же файлом не создаёт дубликаты.

Полный отчёт с количествами записей, результатами проверок и точными путями
резервных копий: `.local/test_dataset_import.json`. Проверяются внешние ключи,
целостность SQLite, согласованность оценок с профилями, сеансов с просмотрами,
кликов с показами и ссылки в личных коллекциях.

Команда повторного безопасного запуска для **того же исходного файла**:

```powershell
.\.venv\Scripts\python.exe merge_test_dataset.py
```

Проверка переноса на малом наборе, включая коллизии ID/email, полный откат,
повторный запуск и сохранение заполненных метаданных:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_dataset_merge.py -v
```
