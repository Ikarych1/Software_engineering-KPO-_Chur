# Небольшая тестовая база КиноСферы

`cinema_sample.sqlite3` — отдельная выборка из полной тестовой базы v3.
Она сохраняет структуру проекта: 30 таблиц, исходные колонки, ключи,
индексы, ограничения и представление `episode_activity`.

Выбраны 100 пользователей и 200 произведений. Комнаты перенесены вместе
со всеми участниками и сообщениями. Сохранены относящиеся к выборке
оценки, отзывы, предпочтения, закладки, клипы, показы, клики, поиски,
сеансы просмотра, прогресс серий и события. Точные количества и размер
приведены в `validation.json`.

## Открыть в DBeaver

1. Распакуйте архив в обычную локальную папку.
2. Создайте подключение **SQLite**.
3. В поле **Path** выберите распакованный `cinema_sample.sqlite3`.
4. Для просмотра откройте таблицу → Data; для запросов — SQL Editor.

Для SQLite-подключения логин и пароль не нужны. Примеры запросов находятся
в `example_queries.sql`. PostgreSQL не открывает SQLite-файл напрямую:
для него требуется отдельный перенос схемы и данных.

Для самостоятельной проверки достаточно Python без сторонних библиотек:
`python verify_sample.py`. Команду нужно выполнить из распакованной папки.

## Что сохраняется при уменьшении

- Идентификаторы, значения оценок, даты и метаданные взяты из исходного
  тестового набора. Новые пользователи, оценки и действия не генерируются.
- Из JSON-профилей удалены ссылки на фильмы, пользователей и комнаты,
  которые не вошли в выборку; список оценок совпадает с таблицей `ratings`.
- События включены только вместе с относящимися к ним сеансами, кликами,
  показами, закладками и другими объектами. Исходные позиции в выдаче
  сохранены, поэтому последовательность `rank` может иметь пропуски.
- Операционные кеши, попытки входа, сбросы паролей и история импорта пусты;
  структура этих таблиц сохранена. Полные видеофайлы в базе не хранятся.
- Пользователи являются тестовыми, а часть взаимодействий в большом
  наборе была смоделирована ранее. Происхождение MovieLens сохранено
  в `MOVIELENS_SOURCE_README.txt`; в этой выборке новые записи не добавлялись.
- Внешние рейтинги и агрегаты в метаданных описывают исходный каталог,
  а не пересчитанную статистику этой маленькой выборки.

Выборка предназначена для проверки структуры, SQL, обработки данных и
интеграции. Она не заменяет полный набор при оценке качества рекомендаций
и нагрузочном тестировании. Рабочая база сайта и большой тестовый файл
при её создании не изменяются.

## Повторная сборка

Из корня исходного проекта при наличии полного тестового набора:

```powershell
.\.venv\Scripts\python.exe datasets/cinema_sample/build_sample.py
```

Скрипт открывает источник только для чтения и создаёт отдельный файл.
Архив для передачи находится в `exports/cinema_sample.zip`.
