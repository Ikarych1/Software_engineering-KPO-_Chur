# Тестовые данные для КиноСферы

Актуальная версия — **cinema_project_v3**: тестовая база и рабочий проект используют одну схему из 30 таблиц. Сохранены штатные `users`, `films`, `user_state`, оценки, прогресс и комнаты. Недостающие данные о поведении хранятся в совместимом расширении проекта.

- [Описание, преобразования и подключение](cinema_project_v3/README.md)
- [Готовая совместимая SQLite-база](cinema_project_v3/cinema_test.sqlite3)
- [ERD проекта и тестовой базы](cinema_project_v3/erd/index.html)
- [Редактируемая ERD](cinema_project_v3/erd/cinema_test.drawio)
- [SQL-запросы](cinema_project_v3/example_queries.sql)
- [Проверка совпадения схемы и данных](cinema_project_v3/validation.json)
- [Проверка настоящим Flask-приложением](cinema_project_v3/app_validation.json)

Версии `cinema_ml32m_v1` и `cinema_ml32m_v2` сохранены как исходные/исторические аналитические наборы. Их отдельная схема не является актуальной схемой проекта. Тестовый контент v3 хранится отдельно от рабочих пользователей сайта.
