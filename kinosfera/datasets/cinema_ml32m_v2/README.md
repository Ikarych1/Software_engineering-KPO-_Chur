# Тестовый датасет КиноСферы — единая модель, версия 2

**Эта аналитическая версия сохранена как источник. Актуальная база со схемой проекта — [cinema_project_v3](../cinema_project_v3/README.md).**

**50 000 пользователей · 3 054 произведения · 24 таблицы · 13 414 770 строк.**
Снимок: 31 октября 2026 года. Формат: UTF-8 CSV.gz; вложенные структуры — JSON в ячейке.

## Одно поле — одно значение

В карточке есть только `imdb_rating`, `tmdb_rating`, `kinopoisk_rating` и соответствующие числа голосов. Параллельных «реальных»/«синтетических» полей нет.

Вместо двух таблиц оценок используется одна **`ratings`**, с одним `score` на `(user_id, movie_id)`. Существующая оценка имеет приоритет независимо от даты дополнения. Сохранены все **6 184 366** исходных оценок MovieLens; добавлены **35 100** оценок только для ранее отсутствующих пар. **16 729** дополнительных кандидатов с существующей оценкой пропущены.

`movie_stats` содержит единые `rating_count` и `rating_mean`. В `users` и `user_activity` используется единый `rating_count`, в журнале активности — `event_count`. Даты и сводки пересчитаны после объединения. Из журнала исключены конфликтующие дополнения оценок и устаревшие промежуточные дополнения; оставшиеся `rating_set` ссылаются на канонические строки `ratings`.

Служебные признаки генерации и отдельный флаг тестовой доступности видео удалены из таблиц. Сведения об источниках находятся в **`provenance.json`**, вне бизнес-схемы и ERD. Технические внешние ID (`source_user_id`, `source_movie_id`, `source_file_id`) сохранены для сопоставления.

## Правило заполнения пропусков

- Существующие значения карточек сохранены без изменений, включая рейтинги IMDb/TMDB, число голосов, тексты и состав участников.
- Недостающие метаданные были дополнены при подготовке исходного тестового снимка; в этой версии новые значения карточек не генерируются заново. Их происхождение перенесено в документацию.
- Отсутствующие внешние ID не выдумываются. `source_movie_id` и `split` у добавленной оценки пусты: она не является наблюдением MovieLens и не получает выдуманное официальное разбиение.
- Ноль, `False` и пустой список выбранных предпочтений не трактуются как пропуск для генерации.
- Отсутствующая коллекция/франшиза может оставаться пустой. `has_video_source` отражает настоящий источник в снимке каталога; наличие моделируемого просмотра не меняет его.

## Ключи, типы и время

`movie_id` совпадает с ID существующего произведения в снимке каталога проекта. `user_id` — отдельный обезличенный ID вида `ml32m_000123`, не аккаунт сайта. Ссылки ограничены этими пользователями и произведениями; чужие фильмотеки не добавлялись.

Временные поля — Unix epoch в UTC. Суффикс `_ms` означает миллисекунды, остальные даты — секунды. Позиции/время просмотра — секунды, `movies.duration_min` — минуты. `user_activity.first_activity_at` учитывает оценки, теги и события; `last_rating_at` — последнюю оценку единой таблицы. `event_count` считает строки общего журнала.

Пустая скалярная ячейка означает NULL/неприменимость; JSON `[]` означает пустой список. PK/FK и допустимость NULL документированы в [ERD](erd/ERD.md), полный список колонок — в `schema.json`, размеры и SHA-256 — в `manifest.json`.

## Происхождение данных

Основа — официальный [MovieLens 32M](https://grouplens.org/datasets/movielens/32m/), отфильтрованный до произведений нашего каталога. Сохранены все исходные оценки и 456 375 тегов. Метаданные взяты из снимка каталога, кеша TMDB и локального официального набора IMDb; пропуски были дополнены в исходном тестовом наборе. **Рейтинги и числа голосов Кинопоиска — тестовые значения.**

Клики, поиски, просмотры, закладки, отзывы, комнаты, клипы и профили моделировались для проверки обработки. Они не являются наблюдавшимися действиями пользователей MovieLens. Имя/email профиля тестовые, адреса заканчиваются `@example.invalid`. В сериаловую структуру входят реальные записи каталога и модельные эпизоды; это не официальный полный перечень серий.

Для оценки качества на реальных наблюдениях выбирайте исходные оценки по `rating_id`, начинающемуся с `r_`, с заполненными `source_movie_id` и `split`. Их временное разбиение сохранено. Добавленные строки имеют ID `sr_` и пустой `split`. Это различие задокументировано, но не создаёт отдельные колонки рейтинга или таблицы.

Условия использования первоисточника сохранены в `MOVIELENS_SOURCE_README.txt`. `provenance.json` содержит происхождение полей карточек, количества дополнений, правило приоритета и контрольную сумму всех сохранённых исходных оценок.

- [ERD в браузере](erd/index.html): обзор и шесть подробных разделов.
- [Редактируемая схема diagrams.net](erd/cinema_test.drawio).

```powershell
.venv\Scripts\python.exe datasets/cinema_ml32m_v2/validate_dataset.py
```

Повторное преобразование исходного отдельного набора версии 1:

```powershell
.venv\Scripts\python.exe datasets/cinema_ml32m_v2/build_dataset.py --source datasets/cinema_ml32m_v1
.venv\Scripts\python.exe datasets/cinema_ml32m_v2/erd/build_erd.py
```

Набор остаётся отдельным от рабочей базы. Преобразование и проверка не открывают базу приложения и не реализуют рекомендации.
